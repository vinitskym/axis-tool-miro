# AXIS TOOL – אפליקציית Miro (אב-טיפוס)

שלוש פעולות בפאנל:
- **סימון:** בוחרים פריטים שכבר נמצאים על הלוח ולוחצים נקודת מוצא, שאלה, תוכן או תובנה. הפריטים לא זזים, אלא מקבלים משטח צבעוני ותווית. לחיצה על סוג אחר מחליפה את הסוג.
- **שאלות מנחות:** שבע הקטגוריות מהמאגר. הקטגוריות המתאימות לפריט שנבחר מופיעות ראשונות. לחיצה על שאלה יוצרת כרטיס שאלה משמאל לפריט ומחברת אותו בחץ.
- **איפה אני?** מספר האלמנטים מכל סוג, שאלות שאין להן עדיין תוכן, תוכן שעוד לא הוביל לתובנה, ובאילו סוגי חשיבה השתמשו.

## התקנה (פעם אחת, כ-20 דקות)

### שלב א: העלאה ל-GitHub (כדי שלאפליקציה תהיה כתובת אינטרנט)
1. נכנסים ל-github.com ומתחברים, או פותחים חשבון חינמי.
2. למעלה מימין לוחצים **+** ואז **New repository**.
   - Repository name: `axis-tool-miro`
   - בוחרים **Public**
   - לוחצים **Create repository**
3. בעמוד שנפתח לוחצים על הקישור **uploading an existing file**.
4. גוררים לחלון את **כל הקבצים** מתוך התיקייה (לא את התיקייה עצמה), ולוחצים **Commit changes**.
5. עוברים ל-**Settings**, ובתפריט הצד ל-**Pages**.
   - תחת Branch בוחרים `main`, ובתיקייה `/ (root)`, ולוחצים **Save**.
6. מחכים 1–2 דקות ומרעננים. למעלה תופיע כתובת בצורה:
   `https://YOUR-USERNAME.github.io/axis-tool-miro/`
   מעתיקים אותה.

### שלב ב: יצירת האפליקציה ב-Miro
1. ב-Miro: לוחצים על תמונת הפרופיל, אחר כך **Settings**, ואז הלשונית **Your apps**.
2. **Create new app**:
   - App name: `AXIS TOOL`
   - בוחרים צוות פיתוח (**Developer team**). אם אין לך, Miro תציע ליצור אחד בחינם.
   - מאשרים ולוחצים **Create app**.
3. בעמוד ההגדרות של האפליקציה:
   - **App URL:** מדביקים את הכתובת מ-GitHub, כולל `/` בסוף.
   - **Permissions:** מסמנים `boards:read` ו-`boards:write`.
4. לוחצים **Install app and get OAuth token**, בוחרים את צוות הפיתוח, ולוחצים **Add**.

### שלב ג: פתיחה בלוח
1. פותחים לוח שנמצא **בתוך צוות הפיתוח**.
2. בסרגל הכלים השמאלי לוחצים **>>** (More apps) ומחפשים את **AXIS TOOL**. כדאי להצמיד אותו (pin).
3. לחיצה על האייקון פותחת את הפאנל.

## עריכת השאלות
ב-GitHub פותחים את `questions.js`, לוחצים על העיפרון (Edit), מתקנים, ולוחצים **Commit changes**. אחרי דקה-שתיים מרעננים את הלוח ב-Miro.

## חשוב לדעת
- **המאגר פומבי:** ה-repository פומבי, כך שכל אחד יכול לראות את הקוד ואת מאגר השאלות.
- **צוותים נוספים:** בשלב הזה האפליקציה מותקנת רק בצוות הפיתוח. כדי להפעיל אותה בצוות של הסטודיו, מתקינים אותה גם בצוות הזה דרך עמוד ההגדרות של האפליקציה.
- **אם משהו לא עובד:** לחיצה ימנית בפאנל, אחר כך Inspect ולשונית Console. העתיקו את השגיאה האדומה.
